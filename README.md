### Textual Entailment using NLP

This project studied the use of  Siamese neural network for solving the textual entailment 
problem using CNN/LSTM/GRU/SBERT. Every instance of this dataset consists of two 
sentences (A and B) and the information whether the sentence (A/B) 
contradicts/neutral/entails the sentence (B/A). We treat this as a seven-category 
classification problem and design a Siamese neural network for solving this 
classification problem.
